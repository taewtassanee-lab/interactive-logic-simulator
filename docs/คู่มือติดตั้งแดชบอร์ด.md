# คู่มือติดตั้งแดชบอร์ดสรุปผลการทำกิจกรรม

เชื่อมต่อเว็บแอปกับ Google Sheets เพื่อให้ครูเห็นความก้าวหน้าของนักเรียนทุกคู่แบบรวมศูนย์

**ใช้เวลาประมาณ 10 นาที ทำครั้งเดียวจบ** และไม่มีค่าใช้จ่าย ใช้บัญชี Google ที่มีอยู่แล้ว

---

## ทำไมต้องตั้งค่านี้

ตามปกติเว็บแอปเก็บข้อมูลไว้ในเบราว์เซอร์ของนักเรียนแต่ละเครื่อง เครื่องครูจึงมองไม่เห็น
เมื่อตั้งค่าเสร็จ ข้อมูลความก้าวหน้าจะถูกส่งมารวมที่ Google Sheets ของครูโดยอัตโนมัติ

**ข้อมูลที่ถูกส่ง** — ห้องเรียน รหัสคู่ ชื่อและเลขที่ของทั้งคู่ ผลการผ่านภารกิจ คะแนนจำลอง
เปอร์เซ็นต์ความครบถ้วนของใบงาน สถานะการสร้าง PDF ชื่อไฟล์ .capx และจำนวนครั้งที่สลับบทบาท

**ข้อมูลที่ไม่ถูกส่ง** — คำตอบเรียงความในใบงานทั้งหมด เพราะคำตอบฉบับเต็มอยู่ในไฟล์ PDF
ที่นักเรียนส่งใน Classroom อยู่แล้ว จึงไม่จำเป็นต้องเก็บซ้ำบนเซิร์ฟเวอร์

---

## ขั้นตอนที่ 1 สร้าง Google Sheet

1. เปิด https://sheets.google.com แล้วสร้างสเปรดชีตเปล่า 1 ไฟล์
2. ตั้งชื่อไฟล์ เช่น `ผลกิจกรรม Logic Simulator ว32281`

---

## ขั้นตอนที่ 2 วางโค้ด Apps Script

1. ในไฟล์ Sheet ที่เพิ่งสร้าง เปิดเมนู **ส่วนขยาย (Extensions)** → **Apps Script**
2. จะมีหน้าต่างใหม่เปิดขึ้น พร้อมโค้ดตัวอย่าง `function myFunction() {}`
3. **ลบโค้ดเดิมทิ้งทั้งหมด** แล้ววางโค้ดจากไฟล์ **`apps-script/Code.local.gs`** ลงไปแทน
   (ไฟล์นี้ใส่รหัสไว้ให้เรียบร้อยแล้ว ไม่ต้องแก้อะไรเพิ่ม)
4. กดบันทึก (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)

> **ทำไมต้องใช้ `Code.local.gs` ไม่ใช่ `Code.gs`**
> `Code.gs` เป็นไฟล์ตัวอย่างที่อยู่ใน GitHub สาธารณะ จึงใส่รหัสจริงไม่ได้
> ส่วน `Code.local.gs` อยู่เฉพาะในเครื่องคุณ ถูกกันไม่ให้ push ขึ้น GitHub ไว้แล้ว

## รหัสที่ระบบสร้างไว้ให้

รหัสทั้งสองอยู่ในไฟล์ `SECRETS-ครูเก็บไว้.txt` ที่โฟลเดอร์โปรเจกต์ (ไฟล์นี้ไม่ถูก push ขึ้น GitHub)

| รหัส | ใช้ทำอะไร | ต้องเก็บเป็นความลับไหม |
| --- | --- | --- |
| `TEACHER_KEY` | ใช้เปิดแดชบอร์ดครู | **ต้องเก็บ ห้ามบอกนักเรียน** |
| `CLASS_SECRET` | ให้เว็บนักเรียนส่งข้อมูลเข้ามา | ไม่ต้อง เพราะฝังอยู่ในโค้ดเว็บสาธารณะอยู่แล้ว |

ถ้าต้องการเปลี่ยนรหัสภายหลัง ให้แก้ทั้งใน Apps Script และใน `src/config.ts` ให้ตรงกัน

## ขั้นตอนที่ 3 รันครั้งแรกเพื่อขอสิทธิ์

1. ที่แถบด้านบนของหน้า Apps Script เลือกฟังก์ชัน **`ตั้งค่าเริ่มต้น`** จากช่องรายการฟังก์ชัน
2. กดปุ่ม **Run**
3. Google จะขอสิทธิ์เข้าถึงสเปรดชีต → กด **Review permissions** → เลือกบัญชีของคุณ
4. หากขึ้นหน้าจอ "Google hasn't verified this app" ให้กด **Advanced** → **Go to (ชื่อโปรเจกต์) (unsafe)** → **Allow**
   (ขึ้นข้อความนี้เพราะเป็นสคริปต์ที่คุณเขียนเอง ยังไม่ได้ส่งให้ Google ตรวจสอบ ซึ่งเป็นเรื่องปกติ)
5. กลับไปดูที่ไฟล์ Sheet จะพบชีตใหม่ 2 ชีตคือ **ผลกิจกรรม** และ **กิจกรรมสด** พร้อมหัวตารางแล้ว

> **เรื่องสิทธิ์ที่ Google ขอ** สคริปต์ขอ 2 อย่างคือเข้าถึง Google Sheets และ Google Drive
> สิทธิ์ Drive ใช้เก็บเฉพาะภาพหน้าจอที่นักเรียนส่งเข้ามาในกิจกรรม SOS เท่านั้น
> ระบบสร้างโฟลเดอร์ชื่อ **ILS-ภาพ SOS จากนักเรียน** ใน Drive ของครู
> ไฟล์ภาพถูกเก็บแบบส่วนตัว ไม่ได้เปิดสิทธิ์ให้ใครเข้าถึงผ่านลิงก์
> จอครูดูภาพได้เพราะต้องใส่รหัสครูก่อนเท่านั้น

## ขั้นตอนที่ 4 เผยแพร่เป็น Web App

1. กดปุ่ม **Deploy** มุมขวาบน → **New deployment**
2. กดไอคอนเฟือง ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่าดังนี้

   | ช่อง | ค่าที่ต้องเลือก |
   | --- | --- |
   | Description | `Logic Simulator Dashboard` (ตั้งชื่ออะไรก็ได้) |
   | Execute as | **Me (อีเมลของคุณ)** |
   | Who has access | **Anyone** |

   > ต้องเลือก **Anyone** เท่านั้น เพราะเว็บของนักเรียนต้องส่งข้อมูลเข้ามาโดยไม่ต้องล็อกอิน
   > ความปลอดภัยอาศัยรหัส `CLASS_SECRET` และ `TEACHER_KEY` ที่ตั้งไว้แทน

4. กด **Deploy** แล้ว **คัดลอก Web app URL** ที่ได้ หน้าตาประมาณนี้

   ```
   https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxx/exec
   ```

## ขั้นตอนที่ 5 ใส่ค่าลงในเว็บแอป

**ส่ง URL ที่คัดลอกได้มาให้ผมในแชท แล้วผมจัดการส่วนที่เหลือให้ทั้งหมด**
(ใส่ค่าใน config, build, push, และทดสอบบนเว็บจริง)

หรือถ้าต้องการทำเอง เปิดไฟล์ [`src/config.ts`](../src/config.ts) หา `SYNC_CONFIG`
แล้วใส่ URL ลงในช่อง `endpoint` ส่วน `classSecret` ใส่ไว้ให้แล้ว

```ts
export const SYNC_CONFIG = {
  endpoint: 'https://script.google.com/macros/s/AKfycbxxxxxxxxxxxx/exec',
  classSecret: 'ใส่ไว้ให้แล้ว ไม่ต้องแก้',
  debounceMs: 4000,
} as const;
```

จากนั้นสั่งอัปเดตเว็บ

```bash
git add -A
git commit -m "เชื่อมต่อแดชบอร์ดกับ Google Sheets"
git push
```

รอประมาณ 1-2 นาที เว็บออนไลน์จะอัปเดตเอง

## ขั้นตอนที่ 6 ทดสอบ

1. เปิดเว็บ https://taewtassanee-lab.github.io/interactive-logic-simulator/
2. กรอกข้อมูลทดสอบแล้วกด **เริ่มกิจกรรม**
3. รอประมาณ 5 วินาที แล้วเปิดไฟล์ Google Sheet ดู ควรมีแถวข้อมูลขึ้นมา
4. กลับมาที่เว็บ เปิดแท็บ **แดชบอร์ดครู** กรอก `TEACHER_KEY` แล้วกด **เปิดดู**
5. ถ้าเห็นตารางข้อมูล แปลว่าติดตั้งสำเร็จ

เมื่อทดสอบเสร็จ ให้ลบแถวทดสอบออกจาก Sheet ได้เลย

## วิธีอัปเดตสคริปต์เมื่อมีความสามารถใหม่

เมื่อระบบเพิ่มความสามารถที่ต้องแก้ฝั่ง Google (เช่น การลบข้อมูลรายคู่) ต้องทำ 3 ขั้นตอนนี้

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ **`apps-script/Code.local.gs`** รุ่นล่าสุดลงไป → Ctrl+S
3. กด **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** → กดไอคอนดินสอแก้ไข →
   ช่อง **เวอร์ชัน** เลือก **เวอร์ชันใหม่** → กด **ทำให้ใช้งานได้**

> ข้อควรระวัง: ต้องเลือก **เวอร์ชันใหม่** ทุกครั้ง ถ้าแค่กดบันทึกโค้ดแล้วไม่ Deploy ใหม่
> เว็บจะยังเรียกใช้สคริปต์รุ่นเก่าอยู่ และ **URL เดิมใช้ได้ต่อไป ไม่ต้องเปลี่ยนใน config**

## การลบข้อมูลรายคู่

ในตารางแดชบอร์ดมีปุ่มถังขยะท้ายทุกแถว กดแล้วจะมีหน้าต่างยืนยันแสดงห้องเรียน รหัสคู่
และชื่อทั้งสองคนให้ตรวจก่อน เมื่อกดยืนยันข้อมูลจะถูกลบออกจาก Google Sheets อย่างถาวร

- ใช้ได้เฉพาะครูที่เปิดแดชบอร์ดด้วย `TEACHER_KEY` แล้วเท่านั้น
- นักเรียนที่มีแค่รหัสห้องเรียนสั่งลบไม่ได้ ระบบจะปฏิเสธ
- **ถ้าคู่นั้นยังเปิดเว็บทำกิจกรรมอยู่ ข้อมูลจะถูกส่งกลับเข้ามาใหม่เมื่อเขาทำอะไรต่อ**
  ถ้าต้องการลบถาวรควรลบหลังจบคาบ หรือให้นักเรียนปิดเว็บก่อน

## ห้องกิจกรรมสด (ใช้แทนระบบตอบรับการมีส่วนร่วมของบุคคลที่สาม)

เปิดแท็บ **แดชบอร์ดครู → ห้องกิจกรรมสด** จะพบคลังกิจกรรมที่เตรียมไว้แล้วตามขั้น GPAS 5 Steps

| กิจกรรม | ใช้ทำอะไร | ขั้น |
| --- | --- | --- |
| คลาวด์คำ | ให้ทั้งห้องพิมพ์คำศัพท์ขึ้นจอพร้อมกัน คำที่ซ้ำมากจะตัวใหญ่ขึ้น | 1 และ 4 |
| แบบทดสอบตรวจอัตโนมัติ | ข้อสอบก่อนเรียน 5 ข้อ ตรวจให้เอง จัดอันดับ และสรุปว่าข้อไหนตอบผิดเยอะ | 1 |
| จับคู่เงื่อนไข | โยงคำสั่ง Condition กับ Action ใช้แทนการโยงเส้นบนสไลด์ | 2 |
| โพลสำรวจด่วน | ถามแบบเลือกตัวเลือก หรือให้ดาว 1-5 พร้อมค่าเฉลี่ย | 2, 3 และ 5 |
| พิมพ์ตอบสั้น | Two Stars and a Wish ข้อความขึ้นเป็นการ์ดบนจอ ใช้แทน Post-it | 4 และ 5 |
| ส่งภาพหน้าจอ SOS | นักเรียนแคปหน้าจอ Event Sheet ที่พังส่งมา ครูดูจากจอตัวเองได้เลย | 3 |

**ขั้นตอนใช้งาน**

1. ครูเลือกห้องเรียนที่มุมขวาบน แล้วกด **เปิดกิจกรรม** ที่กิจกรรมที่ต้องการ
2. บอกนักเรียนด้วยปากเปล่าว่าเปิดแล้ว ให้เข้าแท็บ **กิจกรรมสด** บนไอแพดของตัวเอง
   (ครั้งแรกกรอกห้องเรียนกับชื่อครั้งเดียว เครื่องจะจำไว้ตลอดคาบ)
3. คำตอบจะทยอยขึ้นบนจอครูเอง อัปเดตทุก 5 วินาที
4. เมื่อพอแล้วกด **ปิดรับคำตอบ** แล้วกด **แสดงเฉลย** เพื่ออธิบายร่วมกัน
5. กด **ดาวน์โหลด CSV** เก็บเป็นหลักฐานประกอบการประเมิน

**เครื่องมือหน้าชั้นที่ไม่ต้องใช้อินเทอร์เน็ต** อยู่ในแท็บย่อย **เครื่องมือหน้าชั้น**
มีนาฬิกาจับเวลาจอใหญ่ (ฉายเต็มจอได้ มีเสียงเตือนเมื่อหมดเวลา) และวงล้อสุ่มชื่อ
ที่สุ่มจากรายชื่อจริงที่นักเรียนลงทะเบียนไว้ และไม่สุ่มซ้ำคนเดิมจนกว่าจะกดล้าง

> **ข้อควรรู้เรื่องความเร็ว** เครื่องนักเรียนจะตรวจหากิจกรรมใหม่ให้เองทุก 20 วินาที
> และหยุดตรวจเมื่อส่งคำตอบแล้ว เพื่อไม่ให้ใช้โควตาประมวลผลของ Google หมดภายในคาบเดียว
> ถ้าอยากให้ขึ้นทันที ให้นักเรียนกดปุ่ม **ดูกิจกรรมล่าสุด** ซึ่งเร็วกว่ารอ

## วิธีใช้ในคาบเรียน

- เปิดแท็บ **แดชบอร์ดครู** ทิ้งไว้บนจอครู ระบบรีเฟรชเองทุก 30 วินาที
- ดูได้ทันทีว่าคู่ไหนยังไม่ผ่านภารกิจ จะได้เดินไปช่วยได้ตรงจุด
- ใช้ช่องค้นหากรองเฉพาะห้องที่กำลังสอน เช่น พิมพ์ `ม.5/1`
- กด **ดาวน์โหลด CSV** เมื่อจบคาบ เพื่อเอาไปทำคะแนนหรือเก็บเป็นหลักฐาน

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
| --- | --- |
| ข้อมูลไม่ขึ้นในชีตเลย | ตรวจว่าวางโค้ดจาก `Code.local.gs` (ไม่ใช่ `Code.gs` ที่เป็นตัวอย่าง) |
| กรอกรหัสครูแล้วขึ้นว่ารหัสไม่ถูกต้อง | ตรวจ `TEACHER_KEY` ให้ตรงกัน ระวังช่องว่างท้ายรหัส |
| แดชบอร์ดขึ้นว่าเชื่อมต่อไม่สำเร็จ | ตรวจว่า Deploy ตั้ง Who has access เป็น **Anyone** แล้ว |
| แก้โค้ดสคริปต์แล้วแต่ไม่มีผล | ต้องกด **Deploy → Manage deployments → แก้ไข → Version: New version → Deploy** ทุกครั้ง |
| ข้อมูลของคู่เดิมซ้ำหลายแถว | เกิดเมื่อนักเรียนพิมพ์รหัสคู่หรือห้องเรียนไม่ตรงกัน ให้ตรวจสอบและรวมแถวในชีตเอง |
| กิจกรรมสดขึ้นว่าสคริปต์เป็นรุ่นเก่า | ยังไม่ได้ Deploy โค้ดรุ่นใหม่ ทำตามหัวข้อ "วิธีอัปเดตสคริปต์เมื่อมีความสามารถใหม่" |
| นักเรียนกดส่งแล้วขึ้นว่ากิจกรรมเปลี่ยนไปแล้ว | ครูเปิดกิจกรรมใหม่ทับ ให้นักเรียนกด **ดูกิจกรรมล่าสุด** แล้วตอบใหม่ |
| ห้องเรียนในกิจกรรมสดไม่ตรงกัน | ชื่อห้องที่นักเรียนกรอกต้องตรงกับที่ครูเลือกทุกตัวอักษร เช่น `ม.5/1` ไม่ใช่ `ม.5/1 ` |
| อยากปิดการส่งข้อมูลชั่วคราว | ตั้ง `endpoint: ''` ใน `src/config.ts` แล้ว push ระบบจะกลับไปเก็บในเบราว์เซอร์อย่างเดียว |

## ถ้าไม่ต้องการใช้แดชบอร์ด

ปล่อย `SYNC_CONFIG.endpoint` เป็นค่าว่างไว้ตามเดิม ระบบจะทำงานปกติทุกอย่าง
เก็บข้อมูลในเบราว์เซอร์เท่านั้น ไม่ส่งข้อมูลออกไปไหน และแท็บแดชบอร์ดจะแสดงวิธีติดตั้งแทน
